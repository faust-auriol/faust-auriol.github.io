SAÉ 2.03 — BUT Informatique

Installation et configuration d’une machine virtuelle.

01 — Contexte

Présentation du projet.

Cette SAÉ avait pour objectif d’installer et configurer des services réseau permettant de développer et de déployer des applications communicantes. Nous avons commencé par préparer une machine virtuelle Debian et effectuer sa pré-configuration.

Le projet nous a permis de découvrir l’administration système sous Linux ainsi que les bases de la virtualisation. Nous avons appris à utiliser le balisage léger avec Markdown pour produire une documentation technique. Une partie importante du projet concernait Git et le travail collaboratif à travers un gestionnaire de versions. Nous avons également étudié les protocoles réseau utilisés par Git puis installé Forgejo afin de comprendre le fonctionnement des plateformes de développement collaboratif.

02 — Réalisation

Objectifs & travail réalisé.

  • Préparation d’une machine virtuelle et installation d’un système d’exploitation.
  • Configuration d’un environnement Linux Debian.
  • Utilisation du balisage Markdown.
  • Utilisation de Git et gestion de versions.
  • Installation et configuration de Forgejo.
  • Compréhension des protocoles réseau associés aux services collaboratifs.
