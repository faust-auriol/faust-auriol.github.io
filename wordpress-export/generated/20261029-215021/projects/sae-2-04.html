SAÉ 2.04 — BUT Informatique

Exploitation d’une base de données

← Retour aux projets

Présentation du projet.

Cette SAÉ consistait à exploiter les données publiques de Parcoursup afin de les importer dans une base de données relationnelle puis de les analyser. Nous avons étudié la structure d’un fichier contenant plusieurs milliers d’enregistrements et plus d’une centaine de colonnes.

Après l’importation des données, nous avons réalisé différentes requêtes SQL permettant d’obtenir des informations pertinentes sur les formations et les candidats. Une partie statistique était également demandée afin de confirmer ou d’infirmer plusieurs affirmations à partir des données disponibles.

Cette réalisation nous a permis de comprendre l’importance de l’organisation des données, de leur qualité ainsi que leur utilisation dans l’aide à la décision.

Objectifs & travail réalisé.

  • Importation de données publiques de Parcoursup dans une base de données relationnelle.
  • Étude de la structure d’un fichier comportant plusieurs milliers d’enregistrements et plus d’une centaine de colonnes.
  • Réalisation de requêtes SQL sur les formations et les candidats.
  • Analyse statistique à partir des données disponibles.

Compétences mobilisées.

  • Conception et exploitation d’une base de données relationnelle
  • SQL
  • Importation et nettoyage de données
  • Analyse statistique de données
  • Visualisation et interprétation de résultats
