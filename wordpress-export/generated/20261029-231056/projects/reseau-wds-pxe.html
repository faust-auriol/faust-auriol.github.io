Mise en place d’un réseau WDS / PXE

← Retour aux projets

Présentation du projet.

Ce projet portait sur la mise en place d’un environnement WDS / PXE pour le déploiement Windows par le réseau.

Objectifs & travail réalisé.

  • Mise en place d’un environnement WDS / PXE.
  • Utilisation de DHCP.
  • Démarrage d’une machine depuis le réseau.
  • Configuration du démarrage réseau depuis le BIOS / UEFI.
  • Déploiement Windows par le réseau.

Compétences mobilisées.

  • WDS
  • PXE
  • DHCP
